# Udder Walk: Cyborg Edition

**Play:** https://aemtti.github.io/udder-walk-cyborg/

I couldn't finish Udder Walk myself, so Claude turned the cow into a cyborg.
A C4004 chip on her forehead, Claude at the joystick inside her head, 100 m in 1:13.8.
Press START and keep your hands off. Pressing Q/W/O/P only gets you an ACCESS DENIED.

A just-for-fun fan mod of **Udder Walk** by [@AIMind_Ai](https://x.com/AIMind_Ai)
(original game: https://hilarious-caramel-65855a.netlify.app/). All credit for the original game goes to its creator.
The page bundles three.js (MIT license). Mod made with Claude Code.
